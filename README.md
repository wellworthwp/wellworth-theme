# WellWorth Theme

*Built to serve. Made to last.*

WellWorth is the free, GPL-2.0-or-later WordPress full-site-editing (FSE) block theme purpose-built for mission organisations — small-to-medium churches, registered nonprofits, and mission-driven small businesses. It is distributed on the WordPress.org theme directory and forms the open foundation that the WellWorth Pro plugin suite extends.

- **Licence:** GPL-2.0-or-later (see `LICENSE`).
- **Distribution:** WordPress.org theme directory.
- **Organisation:** [github.com/wellworthwp](https://github.com/wellworthwp).
- **Status:** Scaffolded; theme implementation lands progressively from task **T036** onward.

## Contributing

Issues and pull requests are welcome once the contribution guide is published. Until then, please open a discussion in the org. All UI/UX work must follow the Impeccable invocation flow declared in the PR template.

## Companions

- `wellworth-blocks` — free companion blocks plugin (GPL-2.0-or-later).
- `wellworth-pro` — paid Pro plugin suite (proprietary, GPL-compatible).
- `wellworth-dashboard` — Next.js control plane.
